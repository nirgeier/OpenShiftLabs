# OpenShiftLabs Tasks

- Welcome to the **OpenShiftLabs Tasks** section.
- Each page below contains hands-on tasks/exercises you can complete
  independently to practice specific OpenShift skills.
- Every task includes a short **description**, a real-world **Scenario**, a
  **Hint**, and a collapsible **Solution** with step-by-step `oc` commands.

> **Prerequisites:** a running OpenShift cluster (CRC / OpenShift Local, or any
> cluster) and the `oc` CLI logged in. See
> [Lab 000: Setup & Token](../000-SetupToken/README.md) to get started.
